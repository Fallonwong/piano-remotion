# Agent 提示词示例 — RC6

先安装完整 Skill 和官方 remotion-best-practices，见 [安装说明](../README_使用说明.md)。以下都是制作任务；每个任务仍须先确认谱面、再确认真实关键帧/短试听，最后导出。Agent 自检不能代替用户回复。缺依赖先复用环境，首次安装和大型下载须说明并取得同意。

## 只有 PDF / 五线谱图片 / 简谱图片

```text
使用 $piano-remotion，先读取官方 $remotion-best-practices。
我提供的乐谱是 <路径>，请制作原版钢琴跳跃动效视频。
优先调用已安装的专业 OMR，保留时值、左右手声部、休止符、和弦、延音线和圆滑线。
先向我展示逐小节原谱与重排谱对照、疑点和可编辑 MusicXML，停下来等我确认。
确认后制作关键帧、短试听和连音动态片段，再停下来等我确认；我确认后再完整导出。
没有录音时问我是否用合成音频。不要代填批准，不要编造音符，不要静默识谱一小时。
```

## MusicXML / MIDI / SVG 与时间轴

```text
使用 $piano-remotion，读取官方 $remotion-best-practices。
素材 <路径>，已有工程 <路径>，录音 <MP3 路径，如无则说明>。
复用兼容依赖，保持原跳跃、发光、高亮和运镜。SVG 必须匹配真实排版的音符坐标。
保留 MusicXML/MIDI 的真实音高和时值；缺声部或符号时提出疑点。
完成谱面先展示并等待我确认；随后展示真实关键帧和试听再等我确认，然后导出有声 MP4，验证流与抽样同步。
```

## 只有 MP3

```text
使用 $piano-remotion，读取官方 $remotion-best-practices。
我只有 <MP3 路径>，请制作跟谱钢琴视频。先发现现有转谱/排谱/对齐工具，不强制装整套 CLI。
保留原录音，不额外编配。转谱不确定处要列出；不要假定音频能唯一恢复原谱声部、连线或左右手。
先展示生成的谱面并等待我确认，再展示关键帧与原录音短试听并等待确认，之后导出和验证。
若无法可靠转谱，报告缺口与可选工具，不输出臆造的成片。
```

## 确认后继续

```text
我确认当前 requestId <实际 ID> 的谱面，音频选择 <已有录音/合成/明确无声>。
请制作关键帧和短试听，完成后停下来让我确认。
```

```text
我确认当前 requestId <实际 ID> 的关键帧、连音动态与试听，请导出这版视频并验证。
```

确认必须来自真实用户消息或审阅页下载的回复；上述模板不能由 Agent 自己填写并当作用户批准。内置 Demo 只用于演示，不替代用户歌曲。
