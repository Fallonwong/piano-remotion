# Agent 提示词示例

先安装并读取官方 `remotion-best-practices` 和本 Skill。支持 Skills CLI 时运行：

```sh
npx skills add remotion-dev/skills --skill remotion-best-practices
npx skills add Fallonwong/piano-remotion --skill piano-remotion
```

选择当前 Agent，确认 Skill 已被发现和读取。下面提示词中的尖括号内容需要换成真实路径或要求；文件可通过 Agent 支持的附件方式提供。WorkBuddy 等不支持 `$名称` 调用时，把开头改成“读取官方 remotion-best-practices 的 SKILL.md，再读取 <本 Skill 的绝对路径>/SKILL.md，按其执行”。不要仅粘贴远端原始 SKILL.md，完整目录里的组件和脚本也需要保留。

## 首次体验，没有自己的素材

```text
使用 $piano-remotion，先检查并读取官方 $remotion-best-practices。
我想先体验通用钢琴音符跳跃效果。
优先使用我当前的 Remotion 工程 <工程路径>，检查环境后添加通用示例并打开 Studio 预览。
如果没有现成工程，请在我指定的新目录 <新目录路径> 准备随包独立示例。
保留当前文件和已有入口，先不要导出视频。
```

## 已有 SVG、时间轴和演奏 MP3

```text
使用 $piano-remotion，先读取官方 $remotion-best-practices。
工程：<工程路径>
乐谱 SVG：<SVG 路径>
匹配时间轴：<timeline.json 路径>
演奏音频：<MP3 路径>
请检查素材和帧率，接入我这首曲目的 props，保留原版光点、和弦高亮、双手拖尾和倾斜运镜。
输出画幅为 16:9、1920×1080；标题是 <标题>，个人装饰默认关闭。
先打开实际曲目的预览，检查和弦、换行及开头/中间/结尾同步，报告未通过项，不要用通用 Demo 替代我的曲目。
```

## 只有 MP3

```text
使用 $piano-remotion，先读取官方 $remotion-best-practices。
我只有演奏 MP3：<音频路径>，想制作跟谱音符跳跃预览。
请先检查你已有的音频分析、转谱、排版、谱面坐标映射和对齐能力，优先复用可用的 Skill、工具或库，自主补齐 SVG 和时间轴。
保留原始音频，不擅自添加伴奏，不强制安装整套 CLI。
缺少能力时只指出具体缺失环节和最小配置；涉及新增付费服务或未授权的外部上传时先说明。
最终先预览我的实际曲目，报告转谱不确定处和同步检查结果。当前只要求预览，不要求导出 MP4。
```

## 五线谱图片或简谱图片，可附音频

```text
使用 $piano-remotion，先读取官方 $remotion-best-practices。
我提供的是 <五线谱图片/简谱图片>：<图片路径或附件>。
可选演奏音频：<MP3 路径；没有则写“无”>。
请复用你可用的识谱/视觉工具，核对调号、八度、节奏、连音、反复和声部，生成匹配的五线谱 SVG 与时间轴后接入预览。
保留已有单声部，不额外编配伴奏；看不清且无法可靠确定的信息请具体询问，不要猜。
有音频时检查实际同步；无音频时按谱面速度生成名义时间并明确说明。先打开预览，不导出。
```

图片是识谱来源，当前组件的高亮设计用于五线谱音头，不保证直接在原始简谱数字上逐字高亮。

## 已有 MusicXML/MIDI/SVG，没有 MP3

```text
使用 $piano-remotion，先读取官方 $remotion-best-practices。
我提供 <MusicXML 路径>、<MIDI 路径>、<SVG 路径>，没有录音。
请优先复用标准数据，交叉检查旋律、节奏、反复和谱面版本，只补缺失的排版或音符坐标时间轴。
不要因为没有 MP3 而阻断，也不需要额外安装音频转谱 CLI。
按记谱或 MIDI 的 tempo map 制作无声跟谱预览，说明时间来源和不确定项，先不导出。
```

可只提供其中一种或几种标准素材；删掉没有提供的路径，Agent 会按缺项补齐。

## 预览确认后导出

```text
预览已确认，请继续使用同一首曲目的 props 和素材导出 MP4。
输出分辨率 <宽×高>，帧率 <fps>，输出路径 <完整 MP4 路径>。
如果修改帧率，请同步换算音符事件与 cameraPath 的时间，不要只改 Composition 的 fps。
导出后检查时长、分辨率、帧率、关键帧和音频，报告实际文件位置及尚未解决的问题。
```

无论哪条路线，自动识谱输出、结构校验通过和已验证音乐同步是不同的结果。Agent 应保留可追踪的中间文件与检查记录，不能仅凭工具退出成功就声称全部准确。
