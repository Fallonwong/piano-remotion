# 竖屏纵深跟谱 / portrait-runway

当用户选择纵深跑道式竖屏运镜，或参考视频呈现低机位沿谱推进、近大远小、带尾光点时使用。本方案为参考启发的可执行预设，尚待用户动态审看；不声称像素级复刻。classic 及所有历史作品默认值保持不变。

## 观察与边界

本地参考为 720×1280、30fps、约17.44秒。逐秒总览及8秒附近的逐帧片段显示：双谱表斜向右上远处延伸；开头数秒逐渐靠近，随后较平稳地沿谱推进；背景基本固定；紫/金色声部光点、低幅跳跃、短拖尾与同步和弦高亮。单目成片不能恢复原始3D镜头参数，以下数值为实现起点。

只迁移镜头与动效语法。参考中的夕阳、海面、文字、键盘、音乐和原谱不作为可分发素材。主题、配色、标题、IP继续由具体作品确认。

## 调用

现有 PianoScoreScene 增加可选 cameraMode 和 runwayCamera，默认 classic。ScoreNoteLeap 新增可选 followChordNotes（默认false），此模式开启逐音头分叉/汇聚；保留原有发光、渐细拖尾和延音高亮语义。

```tsx
<PianoScoreScene
  {...approvedSongProps}
  aspectRatio="9:16"
  cameraMode="portrait-runway"
  runwayCamera={{introFrames: 120, leadIn: 70}}
/>
```

timeline.focusPath 仍由真实几何与映射后的表演时间生成，每帧一项；焦点Y取双谱表中心，不能追单个音高。生成方式仍为 camera-path --timeline FILE --systems FILE --out FILE。布局应提供足够长的横向连续谱带，渲染后呈纵深跑道。普通多行谱仍执行原有12–16帧换行过渡；此预设不重排谱面，不保证把离散谱行变成连续道路，换行处必须审看。

镜头参数：1080×1920，中心(540,960)，透视1700，rotateZ=-72°、rotateY=60°、rotateX=0°。120帧内以Smoothstep从scale=.90靠近到1.18，焦点前视70谱面像素逐渐归零；随后跟随focusPath。introFrames=0可取消开场推进。所有时间参数均为帧；30fps下120帧=4秒，24fps下同样4秒应设96帧。camera.scale/rotateZ/rotateX仍可覆盖对应值。

所有谱线、音头、光点共用变换；transformOrigin绑定当前焦点、left=540-fx、top=960-fy，避免全曲越走越放大。新增Y旋转只作用于本模式。CSS透视下远方密集区域仍可能过小、近端可能被裁切，应以真实画面检查，不承诺任意谱面自动适配。

跳动预设：followChordNotes=true、trailFrames=16、highlightFrames=10、trailWidth=2.4、taperTrail=true、glowStrength=1.2、holdHighlightUntilNext=true、starburst=false。弧高继承原场景（右手42、左手34），rightStyle/leftStyle显式配置优先。默认继续右淡紫与左暖橙；新预设固定使用淡紫/落日橙；历史任务的既有配色保持兼容。

每个和弦按实际notes音头坐标生成光点；两音→单音时两条跳跃轨迹汇聚，单音→两音时从共同音头分叉。按谱面Y顺序匹配，避免交叉，不推断声部。汇聚中的光核距离进入18谱面像素时，立即合成为一颗光核与一层光晕，两条拖尾末端同步汇入该点，共用轨迹段只画一次，避免双核挤在一起或叠加变亮；抵达音头时数量对应实际音头数；旧分支拖尾继续按16帧窗口自然渐隐，不在合并瞬间截断。明确systemId变化或旧版坐标换行阈值时不跨行拉线。保留原来的渐细发光尾巴；不要为了参考风格缩短或关闭已有拖尾。

## 审看重点

- 先用已审乐谱前四小节检查起跳、落点、和弦同步与双手音频对齐；风格修改不重新识谱。
- 检查开场、稳定段、最宽和弦、长休止、最末段与换行；不要只看一帧。
- 双谱表演奏中心保持Y约960，标题与IP位于300/400层；遮罩不能侵蚀当前声部。
- 独立几何演示可静音审看，不能代表真实歌曲内容或音画同步通过。
- 新作品仍执行制作配置确认、真实谱面审批、关键帧和试听审批；新增预设不会自动授权全曲导出。
