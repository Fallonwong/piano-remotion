# Production confirmation and presentation

Ask only for missing choices before new score processing or rendering:

Use the [visual configuration matrix](visual-presets.md) for new presets. Recommend 9:16, slate-gray, black-multiply, standard lilac/orange and no character overlay. Ask once for missing camera, FX, typography, pipeline and first-four review choices. Keep legacy theme/custom-color jobs compatible; never infer consent from recommendations.

`production-check --production FILE` checks a `piano-production/v2` object with `aspectRatio`, `theme`, `rightColor`, `leftColor` (six-digit colors), `milestone` (`first-four-keyframes`/`first-four-pilot`), `avatar` (`{kind:'none'}` or `{kind:'asset',src:'public-relative path'}`), `confirmationQuote` and actual `messageRef`. JSON records versions and declarations, not user authentication. `bind` checks props against this configuration. Raw low-level diagnostics do not represent production authorization.

New scene props explicitly set `aspectRatio`. Omitted aspect preserves V1.0.0 geometry, typography, audio fade and layering. Historical explicit-aspect presets (unchanged): portrait 1080x1920, target (540,960), scale 1.18, perspective 1000, tilt (40,-7); landscape 1920x1080, target (920,570), scale 1.28, perspective 1350, tilt (40,-10). Never change defaults of a historical composition to migrate it. The new portrait-focus mode explicitly uses tilt (36,-7); this does not replace the legacy tilt (40,-7).

New scenes need a finite `timeline.focusPath` sample per frame, in the same normalized score coordinate system as all noteheads. Use `camera-path --timeline FILE --systems FILE --out FILE`; systems is an array of `{id,centerY}` measured from the actual layout, and every event has `systemId`. Right-hand targets are preferred, left hand is the fallback. Centers represent the grand staff, not one voice. At a system change use 12..16 frame Smoothstep, `s=t*t*(3-2*t)`, between the old and next focus. Short gaps limit the available window; inspect these transitions. No hardcoded measure-to-frame timing or song-specific Y coordinates.

The stage uses `transformOrigin: fx fy`, `left=targetX-fx`, `top=targetY-fy`, and the existing order `rotateZ rotateX scale` inside a centered perspective parent. The selected pivot has local depth zero. All treble/bass notes cannot simultaneously have depth zero under X tilt: verify that the staff center is stable and note scale does not grow across systems. Do not mix raw SVG pixels with cropped/scaled positions.

Without an explicit new texture selection, paper themes use multiply, dark/custom uses screen with `invert(0.95) hue-rotate(190deg) brightness(1.25) contrast(1.12)` (custom uses contrast 1.18 to remove residual rectangular white-page haze over the background). For custom images, confirm public-relative `backgroundSrc` and freeze that asset. For custom flat colors, confirm six-digit `backgroundColor` and use matching scene `background`. Choose exactly one image or color. No opaque sky/title mask is needed. New mode omits legacy vignettes to preserve active notes; add atmosphere only after checking projected note/trail bounds. Bottom darkening, if separately requested, stays below the playing area and under 34% portrait height. Do not treat a fixed percentage as proof of note clearance.

Title zIndex 300, optional avatar 400. Existing glow/trail component is reused. The indicator palette follows actual hand glow props. Use installed Bodoni/Alimama fonts with disclosed fallback, never automatic font downloads. An explicitly requested generic video overlay stays muted; its loopFrames must come from that supplied asset duration and fps. Portable packages include no private IP/font/media. No full-song render until content/time gates and actual user audition/frame approval. Four-measure direction approval does not certify unseen later content or line transitions.

Optional reference-inspired portrait camera: [portrait-runway](portrait-runway.md). Select it explicitly with cameraMode; no historical defaults change. It requires a measured focusPath and preserves production/content approvals.
