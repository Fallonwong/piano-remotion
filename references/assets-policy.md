# Asset and licensing boundary

Shipped: unchanged ScoreNoteLeap source, public alias, extracted generic scene, portable Node tools, locked runtime metadata, and newly generated geometric/timing fixtures. The short fixtures contain no recording and are not an arrangement of the private song. Fixture SVG is a motion test chart, not a complete engraved piano score; timing.mid and timing.musicxml are separate parser fixtures and are not a synchronized soundtrack for the SVG demo.

Excluded: the original song's MP3, SVG/MusicXML/timeline; all personal videos, character/IP images, brand/credit strings, fonts, source render and unrelated code. Private works remain in the original project untouched. `overlay` defaults off and `credit` defaults empty.

Third-party dependencies are installed from their locked upstream packages and retain their own license terms (including Remotion). They are not relicensed by this package. No node_modules, browser, CLI binary or copied third-party manual is distributed. Do not infer that a working render grants rights to distribute someone else's music, score, font or video.

Source project did not include a license notice for ScoreNoteLeap. See LICENSE.txt for the public licensing decision/status. No provenance beyond user-supplied source has been independently verified.
